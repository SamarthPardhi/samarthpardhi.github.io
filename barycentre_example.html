In the case of our project!

But I am asked to calculate the Barycentres for the Wassertein distance that we calculate for each bin $j$ (where $j \in \{1, \ldots, N\}$). But Barycentre above is for the empirical probability distribution. So I decided to try as follows instead of taking the difference between quantile functions: we can assume each bin as a dataset and calculate their empirical distribution function and hence the barycentres and then calculate the Wasserstein distance between the Barycenter of $F_n$ and Barycenter of $G_n$.

Since, $\alpha_{j} - \alpha_{j-1} = \alpha_{j+1} - \alpha_{j}$ for each $j \in \{2,3, \ldots, N\}$. So, the number of data points in each bin will also be equal.

As you told today, we take the $n$ as number of replications for each quantile $q_{\alpha_j}$ for each $j \in \{ 1, \ldots, N \}$. And then calculate their Barycentres of the quantiles.

def find_nearest_quantile(data, q):
  return np.sort(np.array(data))[(np.ceil(np.array(q) * (len(data) - 1))).astype(int)]
