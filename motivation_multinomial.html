We have a forecaster distribution, $F$ (true distribution) and we would like to test it against other distribution ($G$) to check if it currectly detects the violations by calculating the rejection rates when tested against G. When G is Normal, it will be called size as H0 would be true and when G is t5, t3, st3, it will be called power as H0 would be false. Our one of the main aim is to make sure the test effectively rejects t5 which looks closer to the normal but it is not.

suppose, we fix the $N$ number of VaR levels as, $\alpha_j \;=\; \alpha_1 + (j-1)\frac{1-\alpha_1}{N}$, where $\alpha_0 = 0$, $\alpha_{N+1} = 1$ and $\alpha_1 = 0.975$. Our target is in the tail region, so we won't consider the body region: $(0, 0.975)$. $n$ is the total number of samples.
