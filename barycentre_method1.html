Methodology¶

Let $N$ be the number of Value-at-Risk (VaR) levels to be tested. Define the $\alpha$-levels by

$$ \alpha_j = \alpha_1 + (j-1)\frac{1-\alpha_1}{N}, \qquad j = 1,\ldots,N+1, $$

with $\alpha_0 = 0$ and $\alpha_{N+1} = 1$.

Given $n$ samples from the probability distribution $F$, compute the corresponding empirical quantiles $\hat q_{\alpha_j}$.

Partitioning the sample¶

Define the sets

$$ A_j(\mathbf{L}) = {L_t : \hat{q}_{\alpha_{j-1}} < L_t \le \hat{q}_{\alpha_j}, ; t = 1, \ldots, n}, \qquad j = 1,\ldots,N+1. $$

By construction the intervals are equally spaced:

$$ \alpha_j - \alpha_{j-1} = \alpha_{j+1} - \alpha_j \quad\text{for } j \in {2,\ldots,N+1}. $$

Thus each set $A_j(\mathbf{L})$ contains $k$ elements where

$$ k = \frac{n(1-\alpha_1)}{N}. $$

Write the ordered elements in each interval as

$$ A_j(\mathbf{L}) = {L_j^{(1)}, L_j^{(2)}, \ldots, L_j^{(k)}}, $$

with $L_j^{(1)} \le L_j^{(2)} \le \cdots \le L_j^{(k)}$.

Barycenters¶

The barycenter is computed componentwise across bins $j=2,\ldots,N+1$:

$$ \boldsymbol{\mathcal{Y}}=(\mathcal{Y}_1,\ldots,\mathcal{Y}_k), \qquad \mathcal{Y}_r = \frac{1}{N}\sum_{j=2}^{N+1} L_j^{(r)}, \quad r = 1,\ldots,k. $$

Similarly, compute barycenters for samples from distribution $G$ and denote them

$$ \boldsymbol{\mathcal{Z}}=(\mathcal{Z}_1,\ldots,\mathcal{Z}_k). $$

1D Wasserstein distance¶

The 1D Wasserstein distance between the barycenters $\mathcal{Y} = (Y_1,\ldots,Y_k)$ and $\mathcal{Z} = (Z_1,\ldots,Z_k)$ is

$$ W(\mathcal{Y},\mathcal{Z}) = \frac{1}{n} \sum_{i=1}^k |Y_{(i)} - Z_{(i)}|. $$

If $\mathcal{Y}$ and $\mathcal{Z}$ are not of equal length, interpolation is used (this matches the function wasserstein_1d_scipy).

Feasibility constraint¶

The procedure is valid when $k \ge 1$, i.e.

$$ N \le n(1-\alpha_1) \quad\Longleftrightarrow\quad n \ge \frac{N}{1-\alpha_1}. $$

These constraints ensure each interval contains enough samples for meaningful barycenter computation, controlled by $\alpha_1$. For example, with $\alpha_1 = 0.975$ and $n = 250$, the maximum feasible $N$ is 6; for $N = 64$ the minimum feasible $n$ is 2560.

Note on interpolation and unequal bin sizes¶

If bins have unequal counts, the current approach takes the minimum number of points across bins and computes the barycenter using those minima — this discards data from larger bins. An alternative is to interpolate or resample the order statistics so each bin yields equal-length vectors before averaging; this preserves more information.

Simulation Procedure¶

Hypotheses

  • Null hypothesis ($H_0$): $G = F$ (no difference; distance below critical value)
  • Alternative hypothesis ($H_1$): $G \ne F$ (distributions differ; distance above critical value)

Steps

  1. Draw $n$ samples from $F$.

  2. Fix $N$ and $\alpha_1$ to determine the quantile levels ${\alpha_j}$.

  3. Determine the critical value $B_{\text{crit}}$ by sampling under the null hypothesis ($G=F$), computing the Wasserstein distance for each replication, and taking the $(1-0.05)$-quantile of the resulting distances.

  4. For each replication in the power study:

    • Draw $n$ samples from $G$.
    • Partition each sample into $N$ intervals using the quantiles ${\alpha_j}$, provided the feasibility constraints are met.
    • Compute barycenters $\boldsymbol{\mathcal{Y}}$ and $\boldsymbol{\mathcal{Z}}$ for $F$ and $G$.
    • Calculate the Wasserstein distance $W(\boldsymbol{\mathcal{Y}},\boldsymbol{\mathcal{Z}})$.
    • If $W(\boldsymbol{\mathcal{Y}},\boldsymbol{\mathcal{Z}}) > B_{\text{crit}}$, reject $H_0$.

  5. Return the empirical rejection rate over all replications for each configuration $(n, N, G)$.
